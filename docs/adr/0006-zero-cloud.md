# Zero-cloud: Braid removes its cloud services

Braid had exactly two cloud touchpoints left: AssemblyAI transcribed and diarized the Recording, and Claude wrote the Note. Both are removed. The decision that forced the issue is the Voice Database ([ADR-0007](0007-the-voice-database.md)): storing voiceprints is defensible precisely because this is a private, single-owner app where nothing derived from a voice ever leaves the machine, and that premise is only honest if it is structural. An app that uploads audio to one service and transcript text to another is not that app. So transcription is the local pipeline ADR-0005 built (Apple SpeechTranscriber by default, Parakeet selectable, offline pyannote diarization), and summarisation moves to Apple's on-device foundation model with guided generation, map-reduced over chunks when a Transcript exceeds its context window. The Summariser sits behind the same kind of seam the Engines do, so a stronger local model can replace it if measurement says so.

Two real costs are accepted with eyes open, not discovered later. First, AssemblyAI's diarization measured better than local (it was the very reference our 61 to 71 percent turn-purity numbers were scored against); removing it means accepting worse attribution today and betting on the Voice Database plus Re-attribution to close the gap as the app learns its recurring speakers. Second, Opus-quality prose is given up: a 3B-class on-device model writes the Notes now. The bet is that Preset-structured extraction (Decisions, Action items, Key points) is the kind of constrained task small models do respectably, and the harness culture applies: summary quality is measured against kept fixtures, not assumed.

## Consequences

- **What disappears with the cloud**: both API keys and all account setup; the cost rate table, spend tracking, usage cap and cost frontmatter (nothing is metered because nothing costs anything); the FLAC transcode (it existed only for uploads); the network branch of the failure taxonomy; the Auto-fallback machinery and its disclosure. Setup is now: choose a Vault folder, grant audio permission.
- **Network posture**: the app performs no network I/O except fetching model assets (Parakeet models via FluidAudio, Apple speech assets via the OS). User data, audio, text, and anything derived from them never travel. The Done gate verifies the whole journey with Wi-Fi off.
- **ADR-0002 is now historical**; ADR-0005's local pipeline is what remains, its Cloud/Local/Auto provider modes and fallback are superseded by this decision. "Provider" leaves the vocabulary; the interchangeable local implementations are Engines.
- **The default Engine flips to Apple SpeechTranscriber**, on the evidence: 9 points better turn purity on the real-call fixture, Key Terms support, no model download. Parakeet stays selectable for its word-accuracy edge.
- **Reversal path**: the cloud Adapters live in git history, and the seam they plugged into still exists. Coming back would be a revert plus re-keying, not a rebuild. It would also void ADR-0007's premise, so it is a decision, not a tweak.
